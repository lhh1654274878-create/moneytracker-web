# 钱迹 - Web 版记账应用

## 📱 项目简介

一款简洁易用的**个人记账 Web 应用**，专为 iPhone 用户设计，无需 Mac 即可使用。支持添加到主屏幕后像原生 App 一样运行。

### ✨ 核心特性

- ✅ **离线使用** - PWA 技术，断网也能记账
- ✅ **快速记账** - 3 秒完成一笔记录
- ✅ **数据本地** - localStorage 存储，隐私安全
- ✅ **多分类支持** - 9 种支出分类 + 7 种收入分类
- ✅ **实时统计** - 当月收支、余额自动计算
- ✅ **响应式设计** - 完美适配 iPhone 屏幕

## 🚀 快速开始

### 方法一：本地运行（推荐）

#### 1. 启动本地服务器

**Windows 用户**：

```bash
# 进入项目目录
cd E:\Workbuddy Works\MoneyTracker-Web

# 使用 Python 启动服务器
python -m http.server 8080
```

**如果没有 Python**，使用 Node.js：

```bash
# 全局安装 http-server
npm install -g http-server

# 启动服务器
http-server -p 8080
```

#### 2. 在 iPhone 上访问

1. 确保 iPhone 和电脑**连接同一 WiFi**
2. 查看电脑 IP 地址：
   - Windows: 打开 CMD，输入 `ipconfig`，找到 **IPv4 地址**（如 `192.168.1.100`）
3. iPhone Safari 浏览器打开：`http://你的IP地址:8080`
   - 例如：`http://192.168.1.100:8080`

#### 3. 添加到主屏幕

1. 点击 Safari 底部的**分享按钮** 📤
2. 向下滚动，选择**"添加到主屏幕"**
3. 点击**"添加"**
4. 在主屏幕找到**"钱迹"**图标，像普通 App 一样打开

✅ **完成！** 现在可以断开电脑连接，应用已经安装到 iPhone，支持离线使用。

### 方法二：部署到云端（永久访问）

#### GitHub Pages（免费）

1. 在 GitHub 创建新仓库
2. 上传项目所有文件
3. 仓库设置 → Pages → 选择 `main` 分支
4. 获得网址：`https://你的用户名.github.io/仓库名/`
5. iPhone 访问该网址，添加到主屏幕

#### Vercel / Netlify（免费）

1. 注册 [Vercel](https://vercel.com) 或 [Netlify](https://netlify.com)
2. 连接 GitHub 仓库或直接拖拽文件夹上传
3. 自动部署，获得访问链接
4. iPhone 访问，添加到主屏幕

## 📖 功能说明

### 首页

- **余额卡片**：显示总余额、本月收入、本月支出
- **快捷操作**：一键记收入/支出
- **最近交易**：显示最近 5 条记录

### 添加记录

1. 点击首页的 **"记收入"** 或 **"记支出"**
2. 输入金额（支持小数）
3. 选择分类（餐饮、交通、购物等）
4. 可选添加备注
5. 点击 **"保存"**

### 明细列表

- 查看所有交易记录
- 点击任意记录可删除（需确认）
- 按时间倒序排列

### 分类说明

**支出分类**：餐饮、交通、购物、娱乐、医疗、住房、教育、通讯、其他

**收入分类**：工资、奖金、理财、兼职、礼金、报销、其他

## 💾 数据存储

### 存储方式

- 使用浏览器 **localStorage** 本地存储
- 数据存储在 iPhone 本地，不上传云端
- 卸载浏览器或清除数据会丢失记录

### 数据备份

**当前版本不支持自动备份**，建议：

1. 定期截图记录
2. 手动记录重要数据
3. 后续版本将添加导出功能（CSV/Excel）

## 🔧 常见问题

### Q1: 为什么要添加到主屏幕？

**A**: 添加后可获得：
- ✅ 独立图标，像原生 App
- ✅ 全屏运行，无浏览器地址栏
- ✅ 支持离线使用
- ✅ 更快的启动速度

### Q2: 数据会丢失吗？

**A**: 以下情况会丢失数据：
- ❌ 清除 Safari 浏览器缓存
- ❌ 删除应用图标（从主屏幕移除）
- ❌ 系统存储空间不足时自动清理

**建议**：定期截图备份重要数据。

### Q3: 可以多设备同步吗？

**A**: 当前版本**不支持**云同步。数据仅存储在当前设备。

### Q4: 为什么本地启动时提示"无法访问"？

**A**: 检查：
1. 电脑和 iPhone 是否在**同一 WiFi**
2. IP 地址是否输入正确（不是 `127.0.0.1`）
3. 端口号是否正确（默认 8080）
4. 电脑防火墙是否拦截

### Q5: 可以在 Android 手机用吗？

**A**: 可以！Chrome 浏览器打开后，选择 **"添加到主屏幕"**。
